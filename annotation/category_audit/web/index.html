Category audit: name and format

You will see objects that a model found in videos from head-mounted cameras, some worn by young children and some by adults. Each page is one category, for example duck: the model says every object on the page is a duck. Each page has two steps.

Step 1 · Is it the named object?

You see the crops alone (the object is outlined in pink). Click every crop that is not the named object. Clicked crops turn red; click again to undo. Leave correct ones alone.

Mark as not the object

  • Another kind of thing: a goose or a chicken on a duck page, a toy block on a car page, or the box mostly on something else.
  • Empty: no object in the box, only background (wall, floor, sky).
  • Too unclear: too blurry, dark or small to tell what it is.

Counts as the named object

  • Any example you can recognise, even partly visible or from an odd angle.
  • Toys, pictures, drawings and screens showing it: a rubber duck or a duck in a picture book is a duck here.

Step 2 · Real or depicted?

The same objects come back in a new order, each next to its whole video frame with the object outlined in pink. Click every object that is a toy (including plush toys and toy vehicles), a picture (book, poster, print, drawing, sticker, packaging) or shown on a screen. Leave real objects alone. If an object was not the named thing at all, still answer real or depicted for what it is. Use Enlarge to see a frame bigger.

Step 1 answers are locked once you move on, so judge the crops on their own first.
